# CraveNChat Frontend

React/Vite frontend for CraveNChat.

## Run Locally

```powershell
npm install
copy ".env.example" ".env"
npm run dev
```

By default the app expects the backend API at:

```env
VITE_API_BASE_URL=http://localhost:8080/api
```

See the root `README.md` for full backend, database, and GitHub setup instructions.
